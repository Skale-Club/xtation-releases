# Xtation desktop apps

Windows apps for YouTube, YouTube Music, and your own Home Assistant, built with Tauri and WebView2.

The first stable release is being prepared. Signed installers will be available under [Releases](https://github.com/Skale-Club/xtation-releases/releases).

Home Assistant asks for **your own server address on first launch**. The address stays in your Windows user profile and can be changed or forgotten in Help > Home Assistant address. No personal server is bundled.

Installers are per user. Windows may display a SmartScreen warning because these installers do not have a paid Authenticode certificate. The apps verify update-package signatures separately before installing updates.

This repository contains installers and update feeds. Development and source history are maintained separately.
